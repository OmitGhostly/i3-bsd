# Capitaine Cursors

The default mouse cursor of this desktop: `capitaine-cursors.tar.gz` is the dark variant of
[Capitaine Cursors](https://github.com/keeferrourke/capitaine-cursors) by Keefer Rourke and others,
licensed under the GNU LGPL 3.0 (see `COPYING`).

`install.sh` unpacks it into `~/.local/share/icons/capitaine-cursors` (no package or root needed); Settings > Mouse > Mouse cursor can switch to any other installed theme.

Built unchanged from the upstream source, commit `06c88433662a4004cf56a6e471b523a0a8880be0`, with its own build
script (`./build.sh -d xxhd -t dark`: Inkscape + xcursorgen, sizes 24 to 96 px). The source is at
<https://github.com/keeferrourke/capitaine-cursors>.
